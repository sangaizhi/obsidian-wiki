# 技术：Java

## 基本信息

Java 在当前知识库中对应后端基础能力层，覆盖数据结构容器、并发编程、网络 IO 和 JVM 运行机制。

- [[concepts/概念_Java并发基础|Java 并发基础]]：线程状态、启动终止、线程通信和同步机制。
- [[concepts/概念_Java线程池|Java 线程池]]：线程复用、任务队列、饱和策略和监控。
- [[concepts/概念_Java_NIO|Java NIO]]：Buffer、Channel、Selector。
- [[concepts/概念_JVM类加载|JVM 类加载]]、[[concepts/概念_JVM运行时内存|JVM 运行时内存]]、[[concepts/概念_Java垃圾回收|Java 垃圾回收]]：运行时与性能基础。
