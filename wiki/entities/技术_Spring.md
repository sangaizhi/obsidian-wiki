# 技术：Spring

## 基本信息

Spring 在当前知识库中对应 Java 后端应用框架层，核心是用 IoC/DI 管理对象关系，用 AOP、Web、Data、Messaging 等模块支撑应用开发。

## 相关能力

- [[concepts/概念_Spring核心思想|Spring 核心思想]]：OOP、BOP、AOP、IoC、DI/DL 与模块体系。
- [[concepts/概念_手写Spring框架|手写 Spring 框架]]：用简化框架理解 IoC、DI、MVC 分发链路。
- [[concepts/概念_SpringSecurity|Spring Security]]：过滤器链、认证、授权和拦截器。
- [[concepts/概念_OAuth2|OAuth2]] 与 [[concepts/概念_SpringSocial|Spring Social]]：第三方授权和社交登录。
- [[concepts/概念_SpringCloudConfig|Spring Cloud Config]]：微服务集中配置。
