# 概念：Agent记忆

## 定义

Agent 记忆是为 AI 建立可持久、可检索、可追溯的上下文系统。它不是让大模型本体真正"记住"，而是通过工程系统在需要时把相关记忆取回并放入上下文。

> **Agent Memory ≠ LLM Memory**：Agent 记忆是外部可管理的系统，LLM 记忆是模型内部机制；二者互补而非替代。RAG 是广义记忆的一种实现形式，但本身不是完整的记忆系统。

---

## 记忆分层（传统视角）

### 短期记忆

依赖对话历史。系统把前文聊天记录连同当前问题一起发给模型，制造出"AI 记得"的体验。

问题：
- 上下文窗口有限，长对话会丢失早期信息
- 会话关闭、清空或切换后历史上下文消失
- 全量携带历史增加 Token 成本和噪声

### 长期记忆

三个动作：
- **存储**：保存用户偏好、身份信息、交互规则、历史摘要和关键事实
- **检索**：根据当前问题从记忆库中取回相关片段
- **注入**：把相关记忆作为上下文交给模型

### 判断标准

真正建立长期记忆，必须有文件、数据库或其他持久化记录作为凭据。模型的口头承诺不等于记忆已经建立。

## 记忆的形式（Forms）——按存储维度分类

### 1. 词元级文本形式（Token-Level Textual Form）⭐ 主流

把记忆存成自然语言或结构化文本，放在向量库、日志、图谱里，需要时检索召回。

| 存储策略 | 说明 | 优点 | 缺点 |
|---------|------|------|------|
| **完整交互记录** | 基于长上下文策略，全量存储 | 信息全面 | 计算开销大、推理不稳定 |
| **近期交互记录** | 基于局部性原理，保留最近 N 轮 | 动态更新，聚焦当前 | 远期但关键的信息可能被遗忘 |
| **检索式交互记录** | 基于相关性/重要性/主题选择 | 远期关键记忆可参与决策 | 检索准确性直接影响性能 |
| **外部知识** | 通过 API/MCP 工具获取实时信息 | 扩展真实世界信息访问 | 外部信息可能不准确或有偏 |

### 2. 参数形式（Parametric Form）

记忆编码进模型权重中，不占用提示上下文长度。

| 方法 | 说明 | 代表工作 |
|------|------|---------|
| **微调方法** | 通过监督微调注入领域知识 | Character-LLM, Huatuo（医学）, InvestLM（金融） |
| **记忆编辑** | 直接针对特定事实精准修改，不影响其他知识 | MAC, PersonalityEdit, MEND |

### 3. 潜在形式（Latent Form）

隐式存储于模型内部表征空间（KV 缓存、激活值、隐藏状态），是当前上下文的动态编码。

| 来源 | 说明 |
|------|------|
| **生成（Generate）** | 由独立模型或模块生成可复用的内部表征 |
| **复用（Reuse）** | 继承先前计算过程（如 KV 缓存复用） |
| **转换（Transform）** | 对现有潜在状态蒸馏、池化或压缩 |

> **选择策略：** 频繁回忆近期上下文 → 文本记忆；固化领域知识 → 参数记忆；动态跟踪状态 → 潜在记忆。

## 记忆的来源（Sources）

| 来源 | 说明 | 示例 |
|------|------|------|
| **试验内信息** | 同一任务中多次尝试的经验 | 用户说"不要颐和园"，Agent 调整方案 |
| **跨试验信息** | 跨任务/跨尝试的历史经验 | 从旅行任务中学习用户偏好，用于电影推荐 |
| **外部知识** | 来自工具、API、知识库 | 通过工具获取《北京景点》杂志内容 |

## 记忆的操作生命周期（Operations）

### 记忆形成（Memory Formation）

将原始上下文压缩为紧凑知识，识别出哪些信息值得记住：

1. **语义摘要**：有损压缩，浓缩信息保留全局语义（增量式/分块式）
2. **知识蒸馏**：从交互历史提取可复用的知识（事实→规划策略）
3. **结构化构建**：将无结构数据转化为有组织拓扑（知识图谱、层级树）
4. **潜在表征**：直接编码为潜在空间嵌入向量，避免摘要损失
5. **参数内化**：将外部记忆固化进模型权重（从"检索信息"到"拥有能力"的范式转变）

### 记忆管理（Memory Management / Evolution）

整合新旧记忆，实现：
- 生成更高层次的记忆
- 遗忘不重要或过时的信息
- 解决逻辑冲突

### 记忆检索（Memory Retrieval）

四阶段动态认知过程：

| 阶段 | 说明 |
|------|------|
| **检索时机与意图** | 何时、为何触发检索（快慢双通道推理、潜在状态监测） |
| **查询构建** | 对原始查询语义增强与重构（分解、重写） |
| **检索策略** | 词法检索、语义检索、图检索、混合检索 |
| **检索后处理** | 重排序与过滤、聚合与压缩 |

## 记忆的评估

### 直接评估

| 维度 | 说明 |
|------|------|
| **连贯性（Coherence）** | 召回的记忆是否自然融入当前对话 |
| **合理性（Rationality）** | 记忆内容是否符合常识或事实 |
| **结果正确性** | 能否基于记忆正确回答预设问题 |
| **引用准确性** | 检索到支持最终决策的相关记忆 |
| **时间与硬件开销** | 记忆适配时间 + 推理延迟 |

### 间接评估

通过任务完成效果间接评估——如果任务高度依赖记忆且 Agent 完成了，说明记忆有效。常用场景：对话任务、多源问答、长上下文应用。

## 关键记忆系统（业界标杆）

| 系统 | 核心思路 |
|------|---------|
| **MemGPT** | 借鉴 OS 内存管理，虚拟上下文 + 中断机制，多级记忆 ⭐ |
| **Mem0** | 基于图结构的记忆表示，动态提取整合 |
| **HippoRAG** | 受海马体启发，非参数化长期记忆 |
| **A-MEM** | 借鉴 Zettelkasten 笔记法，动态链接持续演化 |
| **MemOS** | 记忆操作系统，将记忆操作视为可执行动作 |
| **FLEX** | 无梯度前向学习，部署中持续进化 |
| **Zep** | 基于时序知识图谱，时间戳标记事实有效性 |
