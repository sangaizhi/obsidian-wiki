# 概念：Skill 与软件工程

## 定义

Skills 系统不是凭空设计的——它深度映射了经典软件工程原则。理解这些原则，能帮助我们从工程本质理解 Skills 为什么有效，以及如何更好地设计它们。

## 五大原则

### 一、关注点分离（Separation of Concerns）

> "授人以鱼，不如授人以渔。"

Skills 将解决问题的方法、步骤与经验沉淀为**可复用的结构化资产**，而非提供一次性答案。这使得 Agent 从依赖"临时对话灵感"转变为能稳定复现高质量工作流。

**三层架构职责分离：**

| 层级 | 载体 | 职责 | 类比 |
|------|------|------|------|
| 全局规则 | CLAUDE.md | 项目背景、通用规范 | main 函数的全局配置 |
| 专用工作流 | Skills | 特定领域的复杂逻辑封装 | 模块/类 |
| 任务执行 | 子智能体 | 动态规划与实时操作 | 函数调用 |

> ⚠️ **工程师警示**：严禁将所有逻辑写入 CLAUDE.md——就像不要把所有代码写在 main 函数里，这会导致上下文臃肿、维护困难、难以扩展。

### 二、依赖倒置（Dependency Inversion）

**核心机制**：面向接口编程，而非面向实现编程。

大模型不直接依赖 Skill 的具体内部实现，而是依赖其 `description` 和输出契约。

```
┌─────────────┐          ┌──────────────┐
│   大模型     │ ─依赖→  │ description  │ ← 接口/契约
│  (消费者)    │          │ (抽象契约)   │
└─────────────┘          └──────────────┘
                                ↑
                         ┌──────┴──────┐
                         │ SKILL.md    │ ← 具体实现
                         │ reference/  │
                         │ scripts/    │
                         └─────────────┘
```

> 只要保持契约不变，开发者可随时替换、重构或升级 Skill 的内部逻辑。

### 三、惰性加载（Lazy Loading / 渐进式披露）

系统不是在启动时预加载所有知识库，而是在**首次需要特定技能时才加载相关资源**。

对应三层模型：
- **启动时**：仅加载 description（常驻上下文）
- **需要时**：加载 SKILL.md 正文
- **深入时**：加载 reference/、templates/、scripts/

这是"渐进式披露"在软件工程中的根本原理——按需使用，用多少付多少。

### 四、最小权限原则（Least Privilege）

`allowed-tools` 是安全经典原则在 AI 领域的直接映射。

| 传统软件工程 | Skills 系统 |
|-------------|------------|
| 进程只授予完成任务所需的最小权限集 | `allowed-tools` 白名单精确控制 |
| 禁止 root 运行日常服务 | `disable-model-invocation: true` 阻止自动调用 |
| 沙箱隔离 | `context: fork` 子智能体隔离 |

> 明确"不能做什么"比定义"能做什么"更能保障系统安全。

### 五、开放标准（Open Standards）

Anthropic 将 Skills 作为 Agent Skills 的开放标准规范推广，自 2025-12 发布以来，主流 Agent 平台均已提供原生支持。

Skills 成功的三大本质属性：

| 属性 | 含义 | 工程价值 |
|------|------|---------|
| **声明式** | 纯 Markdown 格式，任何大模型均可读取 | 无黑盒二进制，无平台锁定 |
| **自包含** | 一个文件夹即包含全部所需 | 复制即安装，无需复杂依赖管理 |
| **知识本位** | 核心价值在于内容本身而非特定格式 | 不绑定单一平台，可跨工具迁移 |

## 五大原则关系图谱

```
关注点分离 ──→ 三层架构（CLAUDE.md / Skills / 子智能体）
     │
     ├──→ 依赖倒置 ──→ description = 接口契约
     │
     ├──→ 惰性加载 ──→ 渐进式披露 = 按需加载
     │
     ├──→ 最小权限 ──→ allowed-tools = 安全围栏
     │
     └──→ 开放标准 ──→ 声明式 + 自包含 + 知识本位
```
