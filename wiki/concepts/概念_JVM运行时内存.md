# 概念：JVM 运行时内存

## 定义

JVM 运行时内存是 Java 程序运行时被虚拟机划分和管理的内存区域集合。

## 主要区域

- 程序计数器：记录当前线程执行的字节码位置。
- 虚拟机栈：存放栈帧、局部变量表、操作数栈、动态链接和方法出口。
- 本地方法栈：支持 Native 方法调用。
- 堆：对象实例主要分配区域，也是 GC 管理重点。
- 方法区：存放类元数据、常量、静态变量等。
- 运行时常量池：类加载后常量池的运行时表示。
