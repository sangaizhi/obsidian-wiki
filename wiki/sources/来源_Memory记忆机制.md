# AI Agent记忆机制综述

> 原文作者：VoidOc（阿里云技术专家） | 约2.1万字，覆盖300+论文

## 核心要点

- **概念厘清——四种记忆不可混淆**：LLM Memory（模型内部记忆机制，解决上下文长度限制）、RAG（检索增强生成，是广义记忆的一种实现形式）、Agent Memory（Agent作为个体的外部可管理记忆系统——这是本文主角）、Context Engineering（所有记忆技术的统一入口和协调模块）。
- **记忆三来源**：试验内信息（同一任务多次尝试）、跨试验信息（跨任务历史经验）、外部知识（工具/API/知识库获取）。一个模型的记忆来源通常是多样化的。
- **存储三形式**：词元级文本形式（自然语言存于向量库/日志/图谱，可解释性强，主流方案）；参数形式（编码进模型权重，微调或记忆编辑）；潜在形式（KV缓存/激活值/隐藏状态，推理效率高但可解释性弱）。
- **词元级文本的四种存储策略**：完整交互记录（长上下文策略）→ 近期交互记录（局部性原理）→ 检索式交互记录（相关性/重要性/主题选择）→ 外部知识（工具调用获取）。检索式是目前综合最优的方案。
- **记忆三操作——形成/管理/检索的完整闭环**：
  - 形成阶段五种方法：语义摘要（有损压缩）、知识蒸馏（提取可复用知识）、结构化构建（图/树组织，提升多跳推理）、潜在表征（机器原生向量编码）、参数内化（固化进模型权重——"从检索信息到拥有能力"的范式转变）。
  - 管理阶段：通过整合新旧记忆实现更高层次记忆、遗忘不重要信息、解决逻辑冲突。
  - 检索四阶段：检索时机与意图 → 查询构建（分解/重写） → 检索策略（词法/语义/图/混合） → 检索后处理（重排序过滤/聚合压缩）。
- **评估两大策略**：直接评估（主观维度：连贯性+合理性；客观指标：结果正确性+引用准确性+时间硬件开销）和间接评估（对话任务/多源问答/长上下文应用的压力测试）。
- **2020-2026工作汇总**：汇总了MemGPT、A-MEM（借鉴Zettelkasten笔记法）、AgentFold、KARMA、MATRIX、Mem0等大量代表性工作的完整清单。
