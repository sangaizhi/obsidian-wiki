# 来源：工作流 vs Agent

## 来源信息

- 原始文件：`raw/ai/agent/8.工作流 vs Agent.md`
- 主题：工作流、Agent、技术选型、过度设计

## 核心要点

- 工作流是固定流水线，步骤提前设定，确定性强，适合稳定、重复、标准化任务。
- Agent 是智能决策系统，会根据实时环境与反馈动态调整执行路径。
- 自动周报生成适合工作流，因为流程固定、无需大模型也能稳定完成。
- 电商客服更适合 Agent，因为用户问题多变、业务逻辑复杂、场景非结构化。
- 选型法则是固定流程优先工作流，动态决策再引入 Agent。
- 实践上应先搭建稳定工作流覆盖常规需求，再在长尾场景渐进叠加 Agent。
