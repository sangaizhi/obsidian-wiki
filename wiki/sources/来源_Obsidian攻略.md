## 核心要点

### 新手第一天必做的 7 件事

**① 五种同步方案对比**
| 方案 | 适合人群 |
|------|---------|
| iCloud | Apple 全家桶 |
| Obsidian Sync | 跨平台重度用户 |
| OneDrive | Windows 为主 |
| Git/GitHub | 开发者 |
| Syncthing | 折腾党 |

**② iCloud 同步关键设置**：关闭「卸载未使用的 App 时保留数据」

**③ 4 个必做基础配置**：中文界面、相对路径链接、统一附件存放策略、社区插件

**④ Obsidian CLI** 配合自动化工作流

**⑤ Claudian 插件安装** — 侧边栏嵌入 AI 编程代理
- 支持 Claude Code / Codex / Opencode
- 行内编辑 + word-level diff 预览
- @mention 文件、子代理、MCP 服务器
- Plan Mode（先规划再执行）

**⑥ 双向链与笔记属性** — `[[wikilink]]` + YAML frontmatter

**⑦ 附件管理** — 统一存放 + 命名规范
