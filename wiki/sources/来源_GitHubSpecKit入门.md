## 来源信息

- 主题：GitHub Spec Kit、Spec-Driven Development、Claude Code 实践

## 核心要点

- Spec Kit 用规格驱动开发（SDD）替代随意的 Vibe Coding，让开发先明确意图、规格和计划，再进入实现。
- SDD 关键词包括 Intent first、Rich specs、Multi-step refinement、Model-agnostic control。
- 工作流包含 constitution、specify、clarify、plan、analyze、tasks、implement 七步。
- `constitution.md` 定义项目原则，`spec.md` 描述业务需求，`plan.md` 产出技术方案，`tasks.md` 成为 AI 协作实现的任务界面。
- 文章用 Todo App 演示 Spec Kit + Claude Code：初始化项目、建立原则、描述功能、生成方案、生成任务清单、执行实现。
- Spec Kit 更适合新项目、复杂功能、团队协作、生产级原型和遗留系统改造；不适合简单修复或需求尚未明确的探索式开发。
