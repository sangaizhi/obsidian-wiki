# 来源：Agent的规划能力

## 来源信息

- 原始文件：`raw/ai/agent/7.Agent的核心：规划能力.md`
- 主题：Agent 规划能力、CoT、动态规划、决策树

## 核心要点

- Agent 的核心是“给定目标后自己想办法完成”，其中“想办法”就是规划能力。
- CoT 思维链强调先列步骤再执行，优点是清晰易用，缺点是遇到变化容易卡住。
- 动态规划强调感知、决策、执行闭环，每一步都检查结果并在受阻时切换方案。
- 决策树式推演强调行动前模拟多个分支，提前剪掉低胜率路径。
- 规划能力需要平衡思考与行动，过度推演会降低效率。
