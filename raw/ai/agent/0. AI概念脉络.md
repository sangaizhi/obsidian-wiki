# 一、为什么要做Agent

   Agent是智能体的意思，首先要智能，其次要能身体力行，能做事情。目前大模型会说、会推理、会规划、会总结，但是它不能执行，所以我们需要解决大模型不能执行的问题，给大模型装上手脚。所以，一个Agent中，大模型负责“聪明”，是智能的大脑，提供核心的决策依据；Agent框架负责“落地”，具备完整的执行能力，会干、会执行、会控风险，是行动的“手脚”，保障任务的闭环落地；缺一个都不是一个完整的Agent。

- 大模型原生自带，开箱即用的能力
    - 意图理解：精准捕捉用户质量，听懂你要干嘛
    - 基础规划：根据目标，自动累出初步执行步骤
    - 逻辑推理：具备分析、判断能力、复杂算数也能算
    - NLG生成：写文案、代码、聊天，生成流畅文本
    - 思维链（CoT）：像人一样，一步一步的拆解复杂问题
    - 对话总结：长对话后，快速提炼核心关键信息
- Agent框架，大模型不具备的能力
    - 长期记忆 & RAG检索：本地存储历史，检索真正记住你
    - 上下文智能优化：压缩冗余信息，防溢出降Token成本
    - 工具调用与执行：落地实操；
    - 子代理协同调度：拆解任务，多Agent并行处理
    - 多轮循环控制：自主迭代执行，不会干一步就停    
    - Skill / SOP 封装：固定流程标准化，确保执行不会出错
总结：大模型的本质就是“文字接龙”，它只擅长“想、说、理解”，而天生不擅长“动手、记忆、执行”，Agent 弥补大模型的物理执行与记忆短板。
