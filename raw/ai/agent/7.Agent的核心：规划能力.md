当前 AI 界已经有许多Agent，有的Agent只会干死活，一遇到意外就卡壳，有的Agent却能随机应变。其实核心就只有一个：Agent规划能力。

Agent 的核心就是“给个目标，他自己想办法搞定”，而“想办法”这一步，就是规划能力，没有规划能力的Agent，就是个没有脑子的工具人。

Agent 的规划能力：

# 一、COT思维链(Chain Of Throught)

**核心原理** ：先例清单后干活，“先想清楚步骤，再动手”，将大任务拆解为可执行的小步骤。

- 优点
	逻辑链条清晰，上手难度低，执行过程严格按照预设的步骤，不容易出错。

- 缺点
	完全依赖预设步骤，遇到意外情况或者环境变化是，容易卡壳，无法灵活变通。

# 二、动态规划

**核心原理** ：具备“感知-决策-执行”闭环，遇到阻碍自动评估并切换备选方案。

- 优点
    - 实时感知与检查
	    每执行一步都自我检查，确认是否达成预期效果
    
    - 动态决策与切换   
	    一旦发现受阻，立即抛弃原计划，启动B计划或者C计划
    
    - 全程自主闭环    
       无需人工介入，独立解决小意外，确保任务最终交互。
    
# 三、决策树（梦境模拟）

**核心原理** ：Agent在动手前，先在脑海中用决策树做全分支模拟，提前剪掉“坑路”，只保留胜率最高的路径。

当前大模型的思考过程，本质上就是在跑“决策树”，他们不急于落地，而是先推演所有可能，确保每一步都走在最优解上。

**注意** : 要平衡思考与行动，避免过度推演导致效率低下。

**总结** ：决策树是目前最前沿的规划能力，让AI具备了“未卜先知”的能力，通过牺牲一点点计算时间，换取极高的执行准确率和成功率。
