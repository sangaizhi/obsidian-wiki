### 介绍
JAVA NIO 也被称之为New IO 或者 Non Blocking IO，NIO 是同步非阻塞的IO，是从 Java 1.4 版本引入的。NIO 的目的就是用于替换标准IO（BIO）。
### 核心组件
NIO 主要有一下三个核心组件组成：
* Selector
* Channel
* Buffer
### 阻塞与非阻塞
区别阻塞与非阻塞是针对发起 IO 请求操作后，是否有立刻返回一个标志信息而不让请求线程等待。
### 同步与异步
在 Unix IO 模型的环境下，同步与异步的区别就是在数据拷贝阶段是否需要完全由操作系统处理。
异步IO就是有操作系统完成数据的拷贝，拷贝到用户程序的缓冲后通知用用程序。
同步IO就是需要用户程序参与吧数据拷贝到程序缓冲器。
