      SortedMap 是一个关于键的总体排序的Map，是根据键的自然排序进行排序的。或者根据创建时提供的 Comparator 进行排序。

1、在往 SortedMap 中插入元素时，插入的键必须实现 Comparable 接口或者别指定的比较器接受。此外，所有的 key 是可以相互比较的，在比较的时候，不能抛出异常。

2、要正确实现该 Map 接口，则有序映射所维持的顺序（无论是否明确提供比较器）都必须与 equals 一致。

3、特殊方法：

    1)、SubMap
        返回映射表的部分视图，其键值的范围是从 fromKey(包含)到 tokey(不包含)。如果 fromKey 与 toKey 相等，则返回的映射为空。
        另外在更新返回的子映射时，其本身的映射也会被更改，即返回的只是引用。
    2)、headMap
        返回该映射表的部分视图，其键值严格小于 toKey。另外在更新返回的子映射时，其本身的映射也会被更改，即返回的只是引用。
    3)、tailMap：
        返回该映射表的部分视图,其键值大于或等于 fromKey。另外在更新返回的子映射时，其本身的映射也会被更改，即返回的只是引用。
