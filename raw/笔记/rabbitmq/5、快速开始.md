```java
 // 生产端
 // 第一个参数是 exchange ，第二个参数是 routingkey
 channel.basicPublish("", "test001", null,"Hello, RabbitMQ!".getBytes());
```
```java
 // 消费端
 String queueName = "test001";
 channel.queueDeclare(queueName, true, false, false, null);
```
在上面的的代码中，可以看到生产者在发送消息时，指定的是空白的exchange和名称为test001的routingkey，
但是在消费者中，声明的队列的名称是test001,这样，为什么生产者产生的消息为什么可以路由到名称为 test001 的队列，
继而被消费端消费。
在 RabbitMQ 中，生产端发送消息时必须指定一个 Exchange，如果没有指定Exchange，则消息会被发送到Exchange列表中的第一个Exchange,
也就是 AMQP default Exchange，而这个 Exchange 会根据 routingkey 把消息路由到与 routingkey 名称相同的队列中。

管控台关于 AMQP Default Exchange 的说明：The default exchange is implicitly bound to every queue, with a routing key equal to the queue name. It is not possible to explicitly bind to, or unbind from the default exchange. It also cannot be deleted.
