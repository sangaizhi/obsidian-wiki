### 一、为什么要用 Spring Cloud Config?

​    在微服务的系统中，随着业务的发展，微服务会越来越庞大，产生的问题之一就包含大量的服务配置需要管理，而在每个服务里面复杂都维护一套配置就会造成管理复杂。所以，为了解决服务配置的**统一管理**和**实时更新**，Spring Cloud Config 这种配置中心就被造出来了。在 [Spring Cloud 主页](https://spring.io/projects/spring-cloud-config)中，是这样描述 Spring Cloud Config 的功能：Spring Cloud Config  为分布式系统中的外部化配置提供服务器端和客户端支持，通过配置服务器，您可以在一个中心位置管理所有环境中应用程序的外部属性。
