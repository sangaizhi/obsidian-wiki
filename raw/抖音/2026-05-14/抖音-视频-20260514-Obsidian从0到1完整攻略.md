## 🎯 视频核心内容——新手第一天必做的7件事

### 1️⃣ 五种同步方案对比

| 方案 | 适合人群 | 优缺点 |
|------|---------|--------|
| **iCloud** | Apple 全家桶用户 | ✅ 免费、原生集成 ❌ Windows体验差 |
| **官方 Obsidian Sync** | 跨平台重度用户 | ✅ 端到端加密、最稳定 ❌ 付费（$5/月） |
| **OneDrive** | Windows为主 | ✅ 免费、PC生态好 ❌ 移动端冲突多 |
| **Git/GitHub** | 开发者 | ✅ 版本控制 ❌ 有门槛、不适合小白 |
| **自建（Syncthing等）** | 折腾党 | ✅ 免费私有化 ❌ 需自己维护 |

### 2️⃣ iCloud 同步完整步骤 ⭐

> 视频强调的关键点：保留下载 + 关键设置

- 在 macOS 上把 Obsidian 库放在 iCloud Drive
- iOS 端用 iCloud 同步，**关键：关闭「卸载未使用的 App 时保留数据」**
- 避免文件被 iCloud 按需下载策略从本地移除

### 3️⃣ 4个必做基础配置

1. **中文界面** — 设置 → 语言 → 简体中文
2. **链接格式** — 设置文件链接为相对路径，附件链接也统一
3. **附件管理** — 统一附件存放策略（如 `assets/` 文件夹），避免混乱
4. **社区插件** — 开启社区插件并配置安全模式

### 4️⃣ Obsidian CLI 开启

- 安装 Obsidian 命令行工具
- 配合自动化工作流（与 Raycast/Alfred 等配合更香）

### 5️⃣ Claudian 插件安装 ⭐

> 视频亮点——不离开 Obsidian 直接跟 AI 对话

**Claudian**（GitHub: [YishenTu/claudian](https://github.com/YishenTu/claudian)）是一个 Obsidian 插件，能够在侧边栏嵌入 **Claude Code / Codex / Opencode** 等 AI 编程代理：

- 把整个 Vault 当作 AI 的工作目录，支持文件读写、搜索、bash 命令
- **行内编辑** — 选中文本 → 快捷键 → AI 直接修改 + word-level diff 预览
- **@mention** — 提及文件、子代理、MCP 服务器
- **Plan Mode** — 先规划再执行（Shift+Tab 切换）
- **多标签 & 对话历史** — fork、resume、compact

**安装方法：**
1. Obsidian → 设置 → 社区插件 → 搜索 Claudian
2. 或从 GitHub Releases 下载 `main.js`、`manifest.json`、`styles.css` 手动安装
3. 需先安装 Claude Code CLI / Codex CLI
